# Operação segura

## Política de aprovação

| Tipo | Estado inicial | Execução no MVP |
|---|---|---|
| Pesquisa e relatório | concluído/consulta | leitura apenas |
| Recomendação de preço | pendente | simulada após aprovação |
| Campanha/anúncio | pendente | simulada após aprovação |
| Compra de estoque | pendente | simulada após aprovação |

Antes de uma futura integração de escrita: valide usuário de teste, configure limite de gasto, aplique dupla aprovação para anúncios/compras e mantenha um interruptor global desligado por padrão. A aprovação nunca equivale a publicar, cobrar ou comprar nesta versão.
